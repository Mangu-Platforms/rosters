# Banking & Finance

## Checklist

- [ ] Open a business bank account once the entity and EIN exist.
- [ ] Set up the isolated cloud environment and separate keys referenced in Stage I — this is an infra task (see `../../03-Product-OS/infra/environments/`) but the account/billing relationship is a finance task and belongs on this list too.
- [ ] Build the Stage-I cash-needs model. The Feasibility Study (`../../01-Feasibility/Aether_Feasibility_Study.docx`, Section 6) quantifies one piece of this concretely: SOC 2 Type I runs roughly $20,000–$60,000 over 2–3 months, and Type II adds another $30,000–$80,000 over the following 3–9 months. Employment-tax counsel, cyber/E&O/crime insurance, and the payroll-operations "spine" hire's compensation are not quantified there — they're market-dependent — but all three belong in the same model.
- [ ] Size runway against the "six streams, no waiting room" instruction from the Ambition Build Plan — running all six in parallel costs more up front than sequencing them, by design.

## What to file here once it exists

The cash-needs model itself (a spreadsheet), bank account details (not credentials), and a running runway tracker updated at least monthly once the entity is spending.
