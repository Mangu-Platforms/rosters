# Insurance & Risk

Per the Ambition Build Plan, Stage I: *"Cyber, E&O, crime cover bound before any real workforce data enters a disk you control."* This is a hard sequencing rule, not a nice-to-have — it should be bound before the first real (non-synthetic) employee record is loaded into any Aether environment, including a design partner's data used for a proof artifact (see `../../04-GTM-and-Sales/proof-artifact-templates/README.md`).

## Checklist

- [ ] Cyber liability coverage.
- [ ] Errors & omissions (E&O) coverage.
- [ ] Crime coverage (relevant given the money-movement adjacency of payroll, even with a rail partner handling the actual ACH).
- [ ] Confirm coverage is bound — not just quoted — before the first real workforce dataset (a design-partner's actual payroll, not the synthetic NJ crew) is loaded anywhere.
