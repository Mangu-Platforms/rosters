# Entity & Legal

Stage I, from the Ambition Build Plan: *"Entity. Bank. Cap table. Domain."* This folder is where those documents live once they exist. None of them can be produced by an AI session — they need a lawyer and signatures — so what's here is the checklist, in the order the source plan implies.

## Checklist

- [ ] Choose the entity name. Plan's own fallback order if "Aether" is blocked as a trademark: Runwell, Steward, Fieldwork, Lumen.
- [ ] Form the entity (state of formation — confirm with counsel; the two verticals and beachhead states from the product plan don't dictate where to incorporate).
- [ ] Obtain the federal EIN.
- [ ] Draft and execute the cap table / operating agreement.
- [ ] Register the domain.
- [ ] Engage employment-tax counsel — per the Feasibility Study, this should happen alongside entity formation, not after, since the EWA legal memo (see `../../06-Risk-and-Governance/risk-register.md`, item 3) is on the critical path to Stage II's EWA-adjacent work.
- [ ] File for any state-level registrations needed to legally employ or contract in the beachhead states (NJ first, per the plan).

## What to file here once it exists

Formation documents, EIN confirmation letter, cap table (or a link to the platform managing it — Carta, Pulley, etc.), domain registrar account details (not credentials — those belong in a password manager), and the counsel engagement letter.
