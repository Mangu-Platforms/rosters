# Aether — White Paper and Build Bible

Confidential concept. August 2026. Not a live company.

## Verdict

The GitHub repo `Mangu-Platforms/rosters` saw the full picture as a plan. Apps and services were empty README stubs. The Stage II visual model in `03-Product-OS/apps/stage-ii-model/` is the missing surface: five planted errors speak English, and an approver can lock a previewed run without moving dollars.

## The product

Aether is an AI Workforce Operating System for 50–500 employee hourly-heavy firms (construction, home care first; then manufacturing, logistics, multi-unit franchise). Beachhead: NJ / NY / PA.

Tagline: Payroll that runs itself.

Architecture law: rent the rail, own the brain. Tools write exceptions. Models never call ACH.

v1 bundle: copilot + compliance + tax-credit scanner + employer-funded EWA + labor forecast. Health Score and coach are v1.1. Marketplace is year 3+.

## Competitive reality

A copilot alone is dead as a differentiator (Gusto Cofounder, Rippling). Win on vertical rules, credits inside the pay run, employer-funded EWA, and a score a CEO can read in ten seconds.

## Feasibility

Go, with constraints. Market is large enough. Technical year-one path exists via Check/Zeal. Regulatory: WOTC lapsed for new hires after 2025-12-31; EWA is a state patchwork. Operational: one missed tax deposit ends the company; HCM dies in migration.

## How it wins (not a social app)

Jobs shipped one object that made three devices feel stupid. Aether ships one invoice that makes a separate payroll admin, credit consultant, EWA overlay, and BI dashboard feel stupid. Moat is the workforce intelligence graph, earned over labeled exceptions, exits, and collected credits — not the ACH file.
