# Aether Stage II visual model

Palisade Builders LLC. 20 people. Five planted errors in English. An approver can lock a previewed run. No dollars move.

This is the Stage II acceptance test from the Ambition Build Plan, made into a surface a buyer can touch.

## Run

```bash
cd 03-Product-OS/apps/stage-ii-model
npm install
npm run dev
```

## Surfaces

- `/` — landing, three doors
- `/operator` — exception queue (the gate)
- `/operator/run` — line items + lock preview
- `/ceo` — Health Score, next three payrolls, sites on fire
- `/employee` — Maria Delgado, earned wages, Move $200
- `/briefing` — War Room: verdict, features, pages, architecture, feasibility, documents, how it wins

Reset in the header restores the five open exceptions and unpaid EWA.

## Law

Tools write exceptions. Models never call ACH. Auth is off because this is a visual model, not a trust boundary.
