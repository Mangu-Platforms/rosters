# Aether Risk Register

Consolidated from all four source documents plus the Feasibility Study's independent research (`01-Feasibility/Aether_Feasibility_Study.docx`, Section 8). This is meant to be a living document — update it in place rather than starting a new one, and date each change, so it stays the register rather than becoming another snapshot.

| # | Risk | Severity | Status | Mitigation / owner |
|---|---|---|---|---|

## How to use this

Rows 1–3 are new information this session added to what the source documents already knew to watch for; rows 4–10 restate risks the Ambition Build Plan and Operating Plan already named, with owners and current status attached. When a mitigation actually happens (counsel memo delivered, SOC 2 Type I report issued, a rail contract signed), update the **Status** column in place — don't delete the row. A risk that's been mitigated is a fact worth keeping visible, the same way the source plan wants payday risk kept "on a wall," not filed away once it's addressed.
